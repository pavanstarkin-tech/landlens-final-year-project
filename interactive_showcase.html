UPLOADED — Initial Land Entry

The seller registers coordinates, survey boundary polygons, and uploads PDF files (Patta certificate, tax receipts, or deeds). Creates a record in the `properties` table with status set to `UPLOADED`.

Associated API Endpoint: POST /api/properties
